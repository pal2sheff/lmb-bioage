# LMB BioAge

Калькулятор и кабинет врача клиники Love my body: клинические индексы девяти веток, FRAX (автоматический запрос и ручной ввод), авторская исследовательская модель LMB BioAge v0.3.

- `lmb-engine` — расчётный модуль;
- `lmb-server` — сервер и база данных;
- `lmb-web` — интерфейс врача;
- `docs` — техническое задание и контекст проекта.

LMB BioAge — исследовательская модель в процессе разработки и валидации. Все данные в репозитории синтетические. Инструкции для разработки — в `CLAUDE.md`, запуск — в README каждого модуля.
