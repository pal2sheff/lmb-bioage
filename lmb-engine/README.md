# lmb-engine 0.5.0

Расчётный модуль LMB BioAge. Реализует разделы 6–8 ТЗ v1.0 (LMB_BioAge_TZ_v1.0.docx). Модуль не зависит от интерфейса и базы данных и не содержит медицинских параметров, которые не утверждены.

## Что реализовано

| Блок | Состав | Статус |
|---|---|---|
| Индексы | ИМТ, WHtR, ASMI (только из массы мышц конечностей), HOMA-IR, TyG, AIP, non-HDL, eGFR CKD-EPI 2021 (креатинин), ACR, FIB-4, NLR, SII | Рассчитываются |
| Применимость | натощак, инсулинотерапия, СД 1 типа, возраст ≥ 18, IDMS, острое изменение функции почек, FIB-4 < 35 лет, острая инфекция, один образец, подтверждение врачом | Проверяется |
| Ввод | «да / нет / неизвестно»; null вместо пропуска; «<» и «>» не подставляются; только утверждённые конверсии; инсулин в пмоль/л и холестерин в мг/дл отклоняются | Проверяется |
| SCORE2, SCORE2-OP | Формулы для региона high. Параметры в `config/algorithms/*.json` с SHA-256 и источниками. Применимость: 40–69 и 70–89 полных лет, без СД, ССЗ, ХБП, СГХС, очень высокого отдельного фактора; курение «неизвестно» = нет данных. В формулу идёт непрерывный возраст на дату обследования, как в HeartScore | Совпадение с cvd-risk на 30 случаях до 1e−6; HeartScore: 4 из 30 случаев сверены и совпадают (HS01–HS04). До сверки всех 30 индекс не выдаётся (`model_not_configured`) |
| CAIDE | Модель 1 без APOE по таблице владельца (Kivipelto 2006, табл. 2): баллы 0–15; 39–64 полных лет; неизвестная активность = нет данных, а не «неактивен» | Рассчитывается |
| FRAX | Принимает два 10-летних риска от официального сервиса или подтверждённый ручной ввод; применимость 40–90 лет без подмены возраста; формула FRAX не воспроизводится | Работает |
| Модель v0.3 | Проверка конфигурации, Z-оценки (Z_raw и Z_clipped раздельно), правила доменов single / mean / weighted_sum / max / min, вклады, интеграл, блокировка итога с причинами | Нормализация (12 показателей) и правила семи доменов внесены из пакета владельца LMB_Claude_Data_1 (11.10.2026). Итог заблокирован: нет целевой популяции, SCORE2 не сверен полностью |

Веса и постоянная v0.3 зафиксированы в коде. Любое их изменение в конфигурации делает её недопустимой. Muscle и Adaptive имеют вклад null со статусом `not_included`. Правило `mean` — сумма Z, делённая на фиксированное число обязательных входов; при пропуске любого входа домен = null.

Коэффициенты нормализации — авторская исследовательская конфигурация: восстановлены владельцем из описания проекта от 24.09.2026, происхождение и применимость к клинической популяции документально не подтверждены (`parameters_source`, `scientific_status: not_validated` в конфигурации).

Вход нормализации задаётся полем `input` (индекс и единица). Разрешённый пересчёт единиц один: ACR мг/ммоль × 8,84 → мг/г. Возраст в нормализации — полные годы (`age_for_normalization`).

## Исследовательский расчёт v0.3

Результат `pipeline.run` содержит блок `research` (решение владельца 11.10.2026): неизменённая модель v0.3 в режиме `research_mode = local_synthetic`. От клинического итога он отличается одним: отсутствие `target_population` его не блокирует. Остальные условия те же — допустимая конфигурация, все параметры нормализации и правила, все семь доменов, плюс возраст в технической области `research_population` (40–64 полных лет). Блок содержит итог, отклонение, вклады, постоянную, версию и хеш конфигурации, ограничения и причины блокировки. Клинический итог (`status`, `bioage_years`) остаётся заблокированным. Пациентский отчёт исследовательский блок по умолчанию не получает (`lmb-server/lmb_server/report_policy.py`).

## Сверка SCORE2 с HeartScore

Контрольный набор — `tests/fixtures/heartscore_check.csv`: 30 синтетических случаев владельца HS01–HS30 (20 SCORE2, 10 SCORE2-OP, Europe high risk; LMB_Claude_Decisions 11.10.2026). Сверено 30 из 30, оба алгоритма активированы (`heartscore_verified: true`). Прежние случаи C с другими входами — `tests/fixtures/score2_extra_inputs.csv`, без статуса официально сверенных.

1. Откройте калькулятор HeartScore: https://heartscore.escardio.org/Calculate/quickcalculator.aspx?model=high
2. Введите пол, САД, общий холестерин, ЛПВП и курение из строки. Месяц и год рождения выберите так, чтобы возраст на дату проверки был равен `age` полных лет.
3. Запишите месяц/год рождения (`hs_birth_month`, например `01/1986`), дату проверки (`hs_check_date`) и результат точно как показан (`hs_result`: `11%`, `8,8%`, `<1%`).

Тест `test_matches_heartscore` перебирает все дни рождения в указанном месяце и требует совпадения с той точностью, с какой результат показан HeartScore. Значения вида `<1%` хранятся как граница, а не число. Флаг `heartscore_verified` алгоритма допустим только при совпадении всех его эталонов (20 для SCORE2, 10 для SCORE2-OP) — это проверяет `test_checklist_status_and_activation_rule`.

Файл `tests/fixtures/score2_crosscheck.csv` — отдельный эталон независимой реализации cvd-risk (целые годы), он сверку с HeartScore не заменяет.

## Структура

```
lmb_engine/core.py      типы: статусы, «да/нет/неизвестно», наблюдение, визит
lmb_engine/units.py     справочник входов, утверждённые конверсии, технические диапазоны
lmb_engine/gate.py      проверка входов и выбор статуса
lmb_engine/indices.py   клинические индексы и реестр алгоритмов
lmb_engine/cardio.py    SCORE2 и SCORE2-OP
config/algorithms/      параметры опубликованных алгоритмов с источниками
tools/                  генератор контрольных случаев сверки
lmb_engine/model.py     конфигурация, Z-оценки, домены, интеграл v0.3
lmb_engine/pipeline.py  конвейер визита и снимок входов (SHA-256)
config/model_v0.3.json  конфигурация v0.3: веса, нормализация и правила доменов; нет целевой популяции
tests/                  эталоны приложения З и ситуации B-xx
```

## Что нужно, чтобы итог LMB BioAge начал считаться

1. `target_population` в `config/model_v0.3.json` — утверждает владелец.
2. Сверка SCORE2 со всеми 30 случаями HeartScore — иначе домен Cardio не рассчитывается.
3. Для пациентских отчётов — разрешение ответственного врача на конкретную версию (в базе сервера).

Код при этом менять не нужно. Проверка `check_config` перечисляет, чего не хватает. Сквозной численный пример с тестовыми подстановками — `tests/test_normalization_v03.py`.
