# Запуск LMB BioAge на компьютере с Windows (тестовый режим)

Сайт работает только на этом компьютере: адрес `http://127.0.0.1:8000`, с других устройств он недоступен. База данных, файлы и ключи шифрования хранятся в папке `%LOCALAPPDATA%\LMB-BioAge` — отдельно от папки с программой.

В тестовом режиме вход — по почте и паролю, без кода из приложения-аутентификатора. Внешний FRAX не подключён: результат FRAX вносится вручную.

## Установка (один раз)

1. Скачайте программу: на странице репозитория на GitHub нажмите **Code → Download ZIP** и распакуйте архив, например в `C:\LMB\`.
2. Откройте распакованную папку, затем папку `local`, и дважды щёлкните **install.bat**.
3. Программа установит недостающее: Python 3.12, Node.js и PostgreSQL 16. Windows может спросить разрешение — ответьте «Да». Установка занимает 5–15 минут.
4. В конце введите почту, имя и пароль врача (пароль — не короче 12 символов). Это учётная запись для входа на сайт.
5. На рабочем столе появится ярлык **LMB BioAge**.

Сохраните копию файла ключей `%LOCALAPPDATA%\LMB-BioAge\secrets.env` на флешку или в менеджер паролей. Без него ФИО, ИИН, контакты и загруженные файлы восстановить нельзя.

## Работа

- **Запуск:** ярлык **LMB BioAge** на рабочем столе (или `local\start.bat`). Откроется чёрное окно и браузер с сайтом.
- **Остановка:** в чёрном окне нажмите `Ctrl+C`. Если окно закрыли крестиком, база могла остаться запущенной — запустите `local\stop.bat`.
- **Резервная копия:** `local\backup.bat`. Копии базы и файлов появятся в `%LOCALAPPDATA%\LMB-BioAge\backups`. Ключи в копию не входят.

## Обновление

1. Скачайте новый ZIP и распакуйте его на место старой папки программы (данные в `%LOCALAPPDATA%\LMB-BioAge` при этом не трогаются).
2. Запустите `local\install.bat` ещё раз: он обновит пакеты, пересоберёт интерфейс и обновит структуру базы. Учётная запись и ключи сохранятся.

## Если что-то пошло не так

- «Не найден winget» — установите «Установщик приложений» (App Installer) из Microsoft Store.
- Сайт не открывается — посмотрите сообщение в чёрном окне; журнал базы данных: `%LOCALAPPDATA%\LMB-BioAge\postgres.log`.
- Порт 8000 занят — программа сама возьмёт следующий свободный и покажет адрес в окне.
- Состояние установки: в папке программы выполните `.venv\Scripts\python local\lmb_local.py status`.

PostgreSQL-установщик дополнительно создаёт системную службу PostgreSQL на порту 5432. LMB BioAge её не использует: своя база запускается из папки данных только на время работы сайта.
