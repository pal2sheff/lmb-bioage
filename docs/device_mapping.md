# Сопоставление полей LQ One и Visbody

Основание: образцы отчётов, переданные владельцем 10.10.2026. Документ — спецификация для импорта: названия полей, единицы и проверки. Значения из образцов в репозиторий не переносятся (это данные реального человека); для тестов используются синтетические копии структуры.

Общие правила импорта:

- референсные интервалы, оценки и тексты устройства хранятся как «референс устройства» и не используются как нормативы LMB;
- распознанное значение не участвует в расчёте до подтверждения врачом;
- исходный файл хранится через `storage.py` (локально, зашифрованно) и связан с каждым извлечённым значением;
- модель и версию устройства или программы в обоих отчётах указать нельзя: их нет в документе, врач вводит их при импорте (или из настроек клиники).

## 1. LQ One — «Результаты автоматической интерпретации стрессовой нагрузки»

Формат образца: два изображения страниц (PNG). Для надёжного извлечения нужен исходный PDF или экспорт программы.

## 2. Visbody — три отчёта в одном PDF

Формат образца: PDF с текстовым слоем (создан Chromium), извлекается без распознавания изображений. На каждой странице QR-код «Просмотреть отчёт» — признак облачного веб-отчёта; наличие API не подтверждено.

### Шапка

| Код | Поле | Формат значения | Примечание |
|---|---|---|---|
| visbody_measured_at | Дата/время теста | дата-время | см. «Время» ниже |
| visbody_height_cm | Рост | число | см, введён оператором |
| visbody_device_age_years | Возраст | число | не заменяет наш расчёт |
| visbody_score | Оценка | число | баллы устройства |
| visbody_algo_dates | Даты обновления правил | даты (состав, осанка, обхваты) | хранить как версию алгоритма |

### Сегменты

| Код | Левая рука | Правая рука | Туловище | Левая нога | Правая нога |
|---|---|---|---|---|---|
| visbody_seg_muscle_kg | число | число | число | число | число |
| visbody_seg_fat_kg | число | число | число | число | число |

Сумма сегментов мышц в образце меньше «Массы мышц», то есть сегменты — части общей мышечной массы, а не скелетной. Сумма четырёх конечностей — кандидат на массу мышц конечностей. Использовать её как массу мышц конечностей (`visbody_asm`) для ASMI можно только после решения владельца; до этого ASMI имеет статус `model_not_configured`.

### Осанка и обхваты

Осанка (7 показателей: выдвижение головы, наклон головы, округлость плеч L/R, перекос плеч, смещение таза, углы колен L/R, оси ног L/R) и обхваты (шея, плечи L/R, грудь, высокая/средняя/низкая талия, обхват бедра, бёдра L/R и их минимумы, икры L/R) хранятся как дополнительные измерения устройства, `in_model_inputs = false`.

## 3. Проверки, найденные на образце

1. **Время Visbody сдвинуто на час.** Время в отчёте на час позже, чем в имени файла и во времени создания PDF (+05:00). Вероятно, устройство или облако работает в прежнем часовом поясе Астаны (UTC+6). Импорт должен хранить время с явным поясом; поправку утверждает клиника после проверки настроек устройства.
2. **WHR устройства не воспроизводится из его же обхватов.** Ни один из трёх уровней талии, делённый на обхват бедра из того же PDF, не даёт показанного WHR. Для WHtR нужна талия по утверждённому протоколу. Какой уровень Visbody (высокий, средний, низкий) или ручное измерение лентой — решение владельца; без него WHtR из Visbody не считается.
3. **Тождества состава тела сходятся:** ICW + ECW = TBW; TBW + белок + минералы = сухая масса; сухая масса + жир = вес; жир / вес = BFP. Их стоит проверять при каждом импорте как признак правильного распознавания.
4. **LQ One: в образце запись короче 5 минут, достоверность заметно ниже 100 %.** Минимальная длительность и порог достоверности для включения показателя не заданы.
5. **Два «возраста» от устройств** (биологический LQ One и метаболический Visbody) хранятся раздельно со своим источником и не смешиваются друг с другом и с LMB BioAge.

## 4. Решения, нужные от владельца

1. Порог «Достоверности измерения» LQ One и минимальная длина записи, при которых показатель принимается.
2. «МСМ» Visbody — скелетно-мышечная масса? (желательно англоязычный отчёт или документация модели).
3. Можно ли сумму четырёх сегментов «мышца» использовать как массу мышц конечностей для ASMI.
4. Источник окружности талии для WHtR: лента по протоколу клиники или конкретный уровень Visbody.
5. Модель Visbody и версия программы LQ One в клинике.
6. Исходный PDF или файл экспорта LQ One вместо изображений.
