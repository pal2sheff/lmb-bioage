Выводы:

1. Ожидание v0.3 в 3–6 раз ниже SCORE2 оптимального профиля в любом регионе, включая регион низкого риска. Поэтому SCORE2 почти любого пациента оказывается «неблагоприятнее ожидаемого».
2. Смещение растёт с возрастом. Ожидание v0.3 растёт с 40 до 69 лет в 9–13 раз, а SCORE2 оптимального профиля — в 10–16 раз. У человека с оптимальными факторами Z Cardio равен +0,8…+1,5 в 40 лет и +3,4…+3,9 в 69 лет. После ограничения ±3 вклад такого человека в LMB достигает +2,1 года без каких-либо отклонений факторов риска.
3. Несоответствие не объясняется выбором региона. Ни одна калибровка ESC не даёт рисков такого уровня при оптимальных факторах.
4. По имеющимся данным установить, на каком исходе или в какой выборке получено ожидание v0.3, нельзя. Отношение около 3–4 похоже на соотношение фатального и суммарного сердечно-сосудистого риска (например, если ожидание строилось по SCORE 2003). Это лишь гипотеза: её можно проверить только по исходным данным подбора коэффициентов.

## 3. Пример 1 из аудита

Женщина, 55 полных лет, точный возраст 55,61:

- SCORE2 High 3,22300 %;
- ожидание v0.3 0,70842 %;
- Z +2,47832;
- вклад Cardio +1,73483 года.

Все числа совпадают с аудитом. При этом SCORE2 контрольного профиля того же возраста равен 2,57530 %. Значит, около 1,9 из 2,48 единиц Z приходится на смещение ожидания, а не на отличие факторов пациентки от оптимальных.

## 4. Предложение по исправлению (до и после)

**Вариант А — промежуточный, требует утверждения владельцем.** В Z Cardio ожидание v0.3 заменяется на ln(1 + SCORE2 High контрольного профиля того же пола и точного возраста). Разброс 0,365158 и ограничение ±3 сохраняются, вес 0,7 не меняется. Вариант уже реализован как проверочный режим (`experiments.py`, переключатель в «О методике») и на основную модель не влияет.

Подход близок к понятию «сосудистого возраста», где риск пациента сравнивается с риском человека того же возраста с базовыми (оптимальными) факторами риска: для шкал SCORE [3] и для SCORE2/SCORE2-OP [4]. Значения базового профиля в этих работах нужно сверить по полным текстам; здесь используются значения владельца.

|---|---|---|---|---|
| SCORE2 пациента | 3,22300 % | 3,22300 % | 1,98828 % | 1,98828 % |
| Ожидание / контрольный риск | 0,70842 % | 2,57530 % | 0,63771 % | 2,28099 % |

Ограничения варианта А:

- контрольный профиль — условное решение, а не описание популяции;
- разброс 0,365158 подбирался вокруг другого ожидания и выборкой не подтверждён;
- у SCORE2-OP (70+) вариант не применяется.

**Вариант Б — основной, версия v0.4.** Ожидание и разброс подбираются заново на референтной выборке целевой популяции с помощью `refit.py`:

- разделение на обучающую и проверочную части по участникам;
- проверка на отложенных участниках: средняя Z около 0, SD Z около 1.

Механизм готов. Пересчёт заблокирован, пока не заполнена запись `config/reference/v0.4_cardio_reference.json`.

## 5. Почему конфигурация не изменена и каких данных не хватает

Подтверждённых данных о целевой популяции нет, поэтому v0.3 сохранена без изменений. Для обоснованной замены нужны:

1. **Целевая популяция:** возраст, пол, регион, критерии включения. Например, «взрослые 40–69 лет без установленного ССЗ, диабета и ХБП, Казахстан».
2. **Референтная выборка с индивидуальными данными:** возраст, пол, САД, общий холестерин, ЛПВП, курение, исключения применимости SCORE2. Подходят собственные обследования клиники или популяционное исследование. Одних опубликованных средних по возрасту недостаточно: для распределения SCORE2 нужно совместное распределение факторов.
3. **Происхождение коэффициентов v0.3:** исход, по которому строилось ожидание, выборка и метод. Без этого нельзя проверить гипотезу из раздела 2.
4. **Решение владельца по варианту А** как промежуточной редакции модели. Утверждаются контрольный профиль и разброс. Изменение оформляется новой редакцией конфигурации и миграцией со снимком.

PhenoAge для подбора коэффициентов и проверки варианта не используется (решение 11.10.2026).

## 7. Воспроизведение

```bash
cd lmb-engine
python3 -c "
import math; from lmb_engine.cardio import load_params, compute; from lmb_engine.core import Sex
from lmb_engine.model import config_path, load_config
p=load_params('score2'); n=load_config(config_path('model_v0.3.json'))['normalization']['score2']
for sex in (Sex.FEMALE, Sex.MALE):
  for age in (40,45,50,55,60,65,69):
    s=1 if sex==Sex.MALE else 0; e=n['intercept']+n['age_coef']*age+n['sex_coef']*s+n['age_sex_coef']*age*s
    r=compute(p, age, sex, False, 120, 4.5, 1.5)['risk']*100
    print(sex.value, age, round(math.expm1(e),2), round(r,2), round((math.log1p(r)-e)/n['residual_sd'],2))"
```
