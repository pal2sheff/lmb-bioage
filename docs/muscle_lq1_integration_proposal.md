# Мышечный возраст и возраст LQ1 в итоговом LMB: проверка и предложение (12.10.2026)

Основание: задание владельца «Мышечный возраст и возраст LQ1» от 12.10.2026, пункт 4. Документ — предложение на утверждение. **Действующий расчёт не изменён.**

## 1. Что есть в действующей модели

Проверены `config/model_v0.3.json` и `lmb_engine/model.py`.

- Формула v0.3: `DeltaBioAge = 0.08 + 0.7·Cardio + 1.5·Metabolic + 1.3·Renal + 1.0·Hepatic + 1.4·Inflammation + 1.2·Brain + 0.9·Bone`; `LMB = календарный возраст + DeltaBioAge`.
- Веса Muscle и Adaptive в конфигурации — `null`, статус `not_included`. Это не ноль: ветки в формулу не входят.
- Шкалы этих двух веток для итога не заданы. В v0.3 все слагаемые — безразмерные доменные оценки (объединённые Z), умноженные на вес. Мышечный возраст и возраст LQ1 выражены в годах; для перевода в Z нужен масштаб (разброс отклонений в референтной выборке), а его нет.
- Правило неполных данных: итог не считается без всех обязательных доменов, веса не перераспределяются, нули не подставляются.

Вывод: заданных правил для подключения нет, задание веса не устанавливает. Поэтому итоговый LMB считается по v0.3 без изменений. Мышечный возраст и «Возраст по LQ1» рассчитываются и показываются отдельно, с разницей с календарным возрастом.

## 2. Проверка повторного учёта

| Новая оценка | Из чего состоит | Есть ли эти показатели в v0.3 |
|---|---|---|
| Мышечный возраст | сила хвата, пять вставаний, ASMI (сегменты Visbody и рост) | нет; рост входит в v0.3 только через WHtR (талия/рост), напрямую не дублируется |
| Возраст по LQ1 | готовое значение отчёта LQ One (вариабельность ритма сердца) | нет |

При подключении сила хвата, вставания и ASMI в итог отдельно не добавляются — только через мышечный возраст. Показатели LQ One (индекс стресса, ЧСС, спектр ВСР) — только через возраст LQ1.

## 3. Предложение

**Вариант 1 (рекомендуемый): аддитивное расширение с весами и ограничением.**

```text
Δ_muscle = A_muscle − A
Δ_LQ1    = A_LQ1 − A
LMB_ext  = A + DeltaBioAge_v0.3 + w_M · clip(Δ_muscle, ±L) + w_A · clip(Δ_LQ1, ±L)
```

Предлагаемые значения для утверждения: w_M = 0,25, w_A = 0,15, L = 10 лет.

- Максимальный вклад: мышечный ±2,5 года, LQ1 ±1,5 года. Это порядок вкладов действующих веток при Z = ±3: Cardio 2,1; Bone 2,7; Hepatic 3,0; Brain 3,6.
- Веса v0.3 не меняются; разницы входят не целиком (вес < 1) и без перевода в Z.
- Ограничение ±10 лет защищает итог от крайних значений синтетической модели.
- Неполные данные: расширенный итог считается только при наличии и мышечного возраста, и возраста LQ1. Иначе показывается только итог v0.3; отсутствующее не заменяется нулём или календарным возрастом, веса не перераспределяются.
- Оформление: новая редакция модели (кандидат v0.4) с миграцией и снимком конфигурации; прежние расчёты остаются воспроизводимыми.

**Вариант 2: перевод в доменную шкалу.** Z_M = Δ_muscle / s_M, Z_A = Δ_LQ1 / s_A и обычные веса домена. Требует s_M и s_A — разброса отклонений в референтной выборке. Сейчас недоступен.

**Не предлагается:** выпуклая комбинация `A + (1 − w_M − w_A)·Δ_v0.3 + …`. Она меняет действующие веса v0.3.

## 4. Иллюстрация (синтетика, не клинический пример)

Мужчина, 50 лет — синтетический пример 2. LMB v0.3 = 46,875 (Δ = −3,125). Мышечные данные взяты из контрольного примера задания: мышечный возраст 32,74 (Δ = −17,26). Возраст LQ1 = 45 (Δ = −5).

| Веса (w_M, w_A), L = 10 | LMB_ext |
|---|---|
| 0,25 и 0,15 (предложение) | 43,63 |
| 0,30 и 0,20 | 42,88 |
| 0,50 и 0,50 | 39,38 |

Пример показывает чувствительность итога к весам. Из-за синтетического происхождения модели мышечного возраста крайние отклонения возможны (здесь −17 лет), поэтому ограничение обязательно.

## 5. Что нужно для решения

1. Утвердить вариант 1 и значения w_M, w_A, L (или указать свои).
2. Правило неполных данных: только при обеих оценках, как предложено, или иначе.
3. Порог достоверности LQ One, при котором возраст LQ1 допускается в итог.
4. Подтвердить, что мышечный возраст 0.1-synthetic допускается в итог до валидации (он применим только к мужчинам 20–89 лет). Значит, у женщин расширенный итог считаться не будет.
