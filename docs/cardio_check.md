## 3. Проверочный режим `cardio_anchor_experiment_v1`

Параметры: `lmb-engine/config/experiments/cardio_anchor_experiment_v1.json`. Код: `lmb-engine/lmb_engine/experiments.py`.

Вместо ожидания v0.3 по возрасту и полу используется ln(1 + SCORE2 контрольного профиля, %). Контрольный профиль: тот же пол, тот же точный возраст, САД 120, общий холестерин 4,5, ЛПВП 1,5 ммоль/л, без курения. Риск считается той же функцией SCORE2 High.

Нормированная оценка = (ln(1 + SCORE2 пациента) − ln(1 + SCORE2 контроля)) / 0,365158, ограничение ±3. Вклад = 0,7 × оценка. Остальные вклады, веса и свободный член — как в v0.3.

Делитель 0,365158 взят из v0.3 только для проверки влияния замены ожидания и новой выборкой не подтверждён. Режим не является популяционной нормой и не переводит сердечно-сосудистый риск в годы старения. Он включается врачом явно в исследовательской карточке. Основной результат v0.3 при этом не меняется, в отчёт режим не входит.

| | Пример 1: исходная модель | Пример 1: проверочный режим | Пример 2: исходная модель | Пример 2: проверочный режим |
|---|---|---|---|---|
| SCORE2 пациента | 3,22300 % | 3,22300 % | 1,98828 % | 1,98828 % |
| Ожидание / контрольный риск | 0,70842 % | 2,57530 % | — | 2,28099 % |
| Нормированная оценка Cardio | +2,47832 | +0,45596 | +1,64696 | −0,25590 |
| Вклад Cardio | +1,73483 | +0,31917 | +1,15287 | −0,17913 |
| LMB BioAge | 58,60469 | 57,18903 | 46,87509 | 45,54309 |
| Изменение общего результата | — | −1,41565 | — | −1,33200 |
| Разница с PhenoAge | +8,49739 | +7,08174 | +8,79204 | +7,46004 |

Значения примера 1 совпали с контрольными числами владельца. Совпадение с PhenoAge критерием не является.

**Проверки режима.**
- Контрольный профиль даёт нулевой вклад: оба пола, каждый полный год 40–64 (50 случаев).
- Возраст в SCORE2 пациента и контрольного профиля одинаковый.
- При росте SCORE2 вклад не убывает и не превышает 2,1.
- На SCORE2-OP (70+) режим не переносится.
- Если хотя бы один домен не рассчитан, итог отсутствует.
- SCORE2 повторно сверен с HeartScore: 20 из 20 SCORE2 и 10 из 10 SCORE2-OP.

## 4. Нормализация Renal

**Происхождение.** Коэффициенты eGFR и ACR, как и все 12 строк нормализации v0.3, получены из LMB_Claude_Data_1. Владелец восстановил их из описания проекта от 24.09.2026. Референтная выборка, критерии включения и метод оценки не документированы (`reference_sample = null`).

**Пример 1.**
- eGFR (CKD-EPI 2021) 88,0 мл/мин/1,73 м² при ожидании 100,2 → Z +1,37. Знак −1: более низкая СКФ считается менее благоприятной.
- ACR 17,7 мг/г (2,0 мг/ммоль) при ожидании 5,6 мг/г → Z +1,55.
- Правило домена — среднее: (1,37 + 1,55) / 2 = 1,46; вклад 1,3 × 1,46 = +1,90 года.
- Клинически ACR 2,0 мг/ммоль находится в категории A1 по KDIGO (< 3 мг/ммоль), но относительно ожидания нормализации v0.3 даёт положительное отклонение 1,55 SD.
- Обоснованность ожидания ACR 5,6 мг/г для женщины 55 лет без референтной выборки проверить нельзя.

**Предложение, в эту задачу не внесено.** Пересчитать нормализацию Renal (eGFR и ACR, ожидание и разброс) на референтной выборке вместе с Cardio в v0.4. Отдельно проверить преобразование ACR и правило объединения двух показателей в домене. Изменения других веток выносятся на решение владельца отдельно.

## 5. Пересчёт нормализации по реальной выборке (v0.4)

**Запись будущей выборки** — `lmb-engine/config/reference/v0.4_cardio_reference.json`, статус `reference_sample_missing`. Её поля:
- источник и описание выборки, число участников;
- возрастные границы, пол, регион;
- критерии включения и исключения, правила применимости SCORE2;
- метод оценки ожидания и разброса, метод проверки;
- дата и версия.

**Механизм** — `lmb-engine/lmb_engine/refit.py`:
- подбор ожидания T = b0 + b1·возраст + b2·пол + b3·возраст·пол и разброса остатков;
- разделение на обучающую и проверочную части по участникам, а не по визитам;
- проверка на отложенных участниках: средняя Z около 0, SD Z около 1.

Без заполненной записи выборки пересчёт не выполняется, коэффициенты не создаются. Новые коэффициенты получают статус `fitted_not_approved` и требуют утверждения владельцем и новой версии модели. Синтетические тесты 40–64 лет, условный контрольный профиль и 30 случаев HeartScore референтной выборкой не являются.
