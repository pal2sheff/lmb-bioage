# 2 Последовательность нормализации

Age — календарный возраст в годах. Sex: женщина = 0, мужчина = 1. x — исходное значение индекса в предусмотренных единицах; T — преобразованное значение. ln означает натуральный логарифм.

> Expected = Intercept + AgeCoef \* Age  
> + SexCoef \* Sex + AgeSexCoef \* Age \* Sex  
> Z_raw = Sign \* (T - Expected) / ResidualSD  
> Z = min(3, max(-3, Z_raw))

Z — безразмерное отклонение от ожидаемого значения для возраста и пола. ResidualSD — масштаб разброса вокруг этого ожидания; он должен быть строго больше нуля. Sign задаёт направление: положительное Z соответствует неблагоприятному отклонению.

Порядок: проверить вход и единицы → выполнить T → рассчитать Expected → получить Z_raw → ограничить Z диапазоном от −3 до +3 → объединить Z внутри ветки. Исходные значения, Z_raw и Z храни раздельно. Промежуточные значения не округляй.

# 5 FRAX и ручной ввод

Bone использует 10-летний риск основных остеопоротических переломов по модели Казахстана. Риск перелома бедра хранится отдельным полем и не подставляется вместо FRAX major.

При невозможности автоматического запроса обязателен ручной ввод обоих результатов официального расчёта. Сохраняй страновую модель, дату расчёта, источник, способ ввода, исходные параметры и автора записи. Автоматический и ручной результат проходят одинаковую проверку единиц и значений.

Общий LMB BioAge рассчитывается только при полной применимой конфигурации и всех обязательных ветках. Восстановленная таблица не отменяет ограничения исследовательского режима и правила выдачи результата, закреплённые в основном контексте проекта.

Статус набора: 4 из 30 случаев проверены; остальные 26 отсутствуют. Не создавай для них фиктивные эталонные значения. Значения, полученные локальной реализацией формулы, следует обозначать локальным расчётом, пока они не сопоставлены с официальным HeartScore.

Для HS02 сохраняй результат как «\<1%»: comparator = "\<", upper_bound_percent = 1, risk_percent = null. Не подменяй его значениями 0, 0.5 или 1. Такой результат сам по себе не даёт точного численного входа для нормализации SCORE2.

Для остальных случаев: comparator = "=", risk_percent равен 1, 11 или 8.8. Это точность отображения официального калькулятора; не добавляй вымышленные десятичные разряды. Отдельно сохраняй исходную строку результата и дату проверки.
